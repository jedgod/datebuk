# DateBuk Multipurpose Web + Mobile App Pack

Industrial multipurpose dating platform pages for Web App and Mobile App.

## Includes
- Web App: React + Vite pages
- Mobile App: React Native / Expo screens
- Backend: Express API mock server
- Shared feature data model

## Main Modules
- Dashboard
- Explore
- Matches
- Likes Received
- Likes Sent
- Favorites
- Profile Visitors
- Messages
- Voice Connect
- Video Dating
- Date Requests
- Nearby Singles
- Smart Match AI
- Events & Meetups
- My Profile
- Verification Center
- Profile Analytics
- Date Planner
- Premium / Subscription
- Safety Center
- Rewards / Referrals
- Settings
- Help & Support

## Run Web
```bash
cd web
npm install
npm run dev
```

## Run Mobile
```bash
cd mobile
npm install
npx expo start
```

## Run Backend
```bash
cd backend
npm install
npm run dev
```
