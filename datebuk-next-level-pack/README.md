# DateBuk Next-Level Pack

This pack upgrades DateBuk from a starter app into a scalable product foundation.

## What is included

- AI match scoring service
- Trust and Safety workflow
- Identity verification placeholder flow
- Admin moderation dashboard API
- Web app page stubs
- Mobile app screen stubs
- PostgreSQL Prisma schema
- Notification service skeleton
- Subscription and rewards modules
- Docker Compose for API + database

## Run

```bash
cp .env.example .env
docker compose up --build
```

API runs on `http://localhost:5000`.
