# DateBuk DCG v2–v7 integration candidate
No new billing, identity, or subscription tables. Mount in existing Express host at /api/dcg before generic body parsers. Apply SQL 001 then 002 to a scratch database first. Do not run v1 worker alongside this module. Existing v1 queued messages are deliberately excluded; reconcile manually. Global account uniqueness migration can fail if existing duplicate SIDs exist.

## Host contract
Import createGateway from src/gateway.js. Supply existing pg Pool, Redis client, publicBase HTTPS origin, live:false, and host adapters: authenticate Express middleware populating verified identity {tenantId,userId,role,stepUp}; csrf middleware; entitlement(transaction,identity,feature) returning {allowed,limit,period,subjectId} from the existing subscription authority (canonical billing period and quota owner); resolveNotification(transaction,identity,request) returning {to,body,consent} from authorized recipient, approved template and current consent. Never trust client roles, recipient numbers or message bodies. Host must enforce staff permissions and tenant membership. Mount router and call dispatchOne from a supervised worker loop only after release approval. Set DCG_ENCRYPTION_KEY_HEX to a securely stored random 32-byte hex key. Configure inbound webhook /api/dcg/webhooks/<account UUID>/inbound in Twilio. React component is a basic dashboard, not shadcn integration. Install dependencies with npm install in isolated environment; npm test runs dependency-free unit tests.

## Release gates (NOT PASSED)
Actual repository unavailable in GitHub search. Host adapters not implemented against real schema. No live Twilio or database tests. No API key auth, credential rotation, Verify OTP, inbound reply routing, START/HELP workflow, delivery reconciliation UI, spend cap, segment-based quota, consent recheck at dispatch, stale claim recovery, retention job, Docker or end-to-end tests. Redis is rate limiting only; PostgreSQL is durable queue. Ambiguous provider failures are never automatically retried; manually reconcile uncertain/dispatching records before any resend. Disable/STOP can race with an already claimed send. Quota is one per accepted request, not per segment. Do not enable live until these gaps are resolved. Validate sender campaign registration, webhook canonical URL, replay/order, tenant isolation, quota concurrency, subscription downgrade, consent revocation, provider timeout and crash scenarios with real integration tests. Review secrets and PII retention. No production credentials included.
