# DateBuk Industrial Feature Pages

A ready-to-run React/Vite downloadable pack for DateBuk sidebar feature landing pages.

## Includes
- Industrial responsive sidebar
- Likes Received / Likes Sent / Favorites
- Profile Visitors with charts
- Verification Center/KYC layout
- Voice Connect, Video Dating, Date Requests landing screens
- Nearby Singles map-style page
- Smart Match AI radar analytics
- Date Planner
- Safety Center, Report & Block, Privacy Controls
- Profile Analytics
- Events, Rewards, Referrals, Badges
- Right-side real-time chat panel

## Run
```bash
npm install
npm run dev
```
Open the local Vite URL shown in your terminal.

## Build
```bash
npm run build
```
